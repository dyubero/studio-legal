Privacy Policy

Studio · Last updated: October 29, 2026

Studio is a private desktop application that a single creator uses to publish videos to their own YouTube channels. This policy explains what data Studio accesses, how it is used and stored, and how access can be revoked.

YouTube API Services

Studio uses the YouTube API Services. By using Studio you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

What data Studio accesses

When the channel owner connects a YouTube channel, Studio asks Google for permission to:

  • upload videos, thumbnails and captions to that channel, and edit their titles, descriptions, tags, playlists and publication settings;
  • read and update the channel's description and branding;
  • read the channel's own videos, playlists and comments;
  • read the channel's YouTube Analytics reports (for example views, watch time and audience retention).

Studio only accesses channels that their owner has explicitly connected. It does not access other users' private data, and it does not collect personal information about viewers beyond the aggregated, anonymous statistics that YouTube Analytics provides to the channel owner.

How the data is used

The data is used only to publish and manage the owner's own videos and to show the owner how those videos perform. It is not sold, not used for advertising, and not shared with any third party.

How the data is stored

Studio runs on the owner's own computer. The access tokens issued by Google and any analytics retrieved are stored locally on that computer only. Studio has no server and does not send this data anywhere except to Google's APIs. Analytics data is refreshed from YouTube and is not kept for longer than 30 days without being refreshed. Studio does not use cookies or tracking technologies.

Revoking access and deleting data

Access can be revoked at any time from the Google security settings page. Once access is revoked, Studio can no longer reach the account, and the locally stored tokens and analytics can be deleted by removing them from the computer where Studio runs. To request deletion or ask any question about this policy, write to the contact address below.
