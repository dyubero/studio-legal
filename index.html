Studio

A private production tool for a small group of educational YouTube channels.

Studio is a desktop application run by a single creator on their own computer. It produces explainer videos about astronomy, engineering, geography, history and science, and publishes them to the creator's own YouTube channels: Lookback, Cutaway, Meridian, Small Print and Second Look.

What it does with YouTube

  • Uploads finished videos to the creator's own channels, with their title, description, chapters, tags, thumbnail and subtitles.
  • Schedules publication dates and organizes videos into playlists.
  • Keeps each channel's description and branding up to date.
  • Reads the channels' own analytics (views, audience retention) so the creator can see which parts of a video work.

Studio is not offered to the public and does not access any account other than the creator's own. It uses the YouTube API Services; by using them it is bound by the YouTube Terms of Service.
